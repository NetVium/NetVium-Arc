✨ What it does
Live fleet dashboard — health status, CPU / memory / disk usage, thresholds & alerts
Server inventory — organize servers into groups with per-group thresholds
Processes — view and manage processes on any connected server
Large file finder — hunt down space-hogging files across servers
Connectivity & time-sync checks — spot network drift and NTP issues
Log watch — tail and search remote logs in real time
SFTP file browser — upload / download files through a familiar interface
Multi-user — Admin & Viewer roles, brute-force lockout, audit log
Dark & light themes — plus a fully responsive layout
📥 Install
Go to Releases
Download the latest NetVium-Arc-Setup-v4.0.exe
Run the installer, launch NetVium Arc, log in
(admin / admin@123 — change it in Users → admin right away)
Silent install: NetVium-Arc-Setup-v4.0.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART
